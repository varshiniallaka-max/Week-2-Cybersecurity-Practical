# Week 2 – Cybersecurity & Ethical Hacking Practical

## Project Overview

This repository contains the practical activities completed during Week 2 of my Cybersecurity and Ethical Hacking internship.

The main focus of this week was Footprinting, Reconnaissance, Information Gathering, Google Hacking Database (GHDB), and Network Scanning.

The repository includes practical explanations, commands, screenshots, observations, results, and the project report.

## Objectives

- Understand the fundamentals of footprinting and reconnaissance.
- Learn how to collect publicly available information about domains.
- Explore Google Dorks using the Google Hacking Database.
- Understand domain and email relationships using Maltego.
- Perform information gathering using theHarvester.
- Perform network discovery using Nmap and Zenmap.
- Understand the security implications of information exposed online.

## PM1 – Footprinting and Reconnaissance Using Multiple Tools

### Objective
To understand how to collect domain information and identify web technologies and security-related configurations.

### Activities Performed

**1. DNS Lookup – Nslookup**

Command:
```bash
nslookup networkwalks.com
```

Observation:
- DNS resolution was successful.
- The domain resolved to IP address `192.232.216.135`.

**2. HTTP Header Inspection – Curl**

Command:
```bash
curl -I https://networkwalks.com
```

Observation:
- HTTP response: `HTTP/2 200`
- Server information: Apache
- WordPress-related metadata was visible.
- HTTP response headers were successfully retrieved.

**3. Web Application Firewall Detection – WAFW00F**

Command:
```bash
wafw00f networkwalks.com
```

Observation:
- WAFW00F identified ModSecurity (SpiderLabs).
- The tool reported two requests.

**4. WhatWeb**

WhatWeb was included in the practical work to identify technologies used by web applications. WordPress-related technology information is visible in the supplied terminal evidence.

### Result
Domain resolution, HTTP header inspection and WAF fingerprinting were demonstrated successfully.

## PM4 – Footprinting and Reconnaissance Using theHarvester

### Objective
To understand how theHarvester collects publicly available email, IP address and hostname information.

### Activities Performed

- Executed theHarvester against `microsoft.com`.
- Examined the output generated by the selected information source.
- Observed email-related results.
- Examined connection errors and incomplete collection results.

### Observation

The supplied output showed:
- One email-like result.
- No IP addresses found.
- No people found.
- No hosts found.
- Repeated server-disconnected messages.

### Result

TheHarvester executed and returned partial information. Some collection requests failed because of source connection errors.

## PM5 – Network Scanning Using Nmap and Zenmap

### Objective
To understand basic network discovery and identify active hosts.

### Activities Performed

- Downloaded Nmap for Windows.
- Installed Npcap.
- Opened Zenmap.
- Entered the target IP address `10.0.0.2`.
- Selected the Ping Scan profile.
- Executed the scan.

### Observation

The scan output displayed:
- Target: `10.0.0.2`
- Host status: Up
- IP addresses scanned: 1
- Hosts up: 1
- Scan duration: 1.18 seconds

### Result

Successfully performed a single-host ping scan using Zenmap and identified the target as active.
